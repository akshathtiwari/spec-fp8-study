# Superseded

The paper's canonical source is **`paper/paper.tex`**, which builds to
`paper/paper.pdf`.

This markdown draft was the working version while the results were still
landing. It is removed rather than kept in sync because two sources for one
document is exactly the drift this study is about: the LaTeX and the
markdown had already diverged on several figures by the time the grid
finished, and `analysis/check_paper.py` was checking the wrong one.
